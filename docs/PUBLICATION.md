# GitHub 发布与来源权限清单

## 交付内容

真实运行包 `knowledge/`、检查/启动脚本、测试、原创手册、README、架构与工作流、源码指南、演示脚本、面试问答，以及脱敏验证摘要。不是只有截图与README的空壳。

## 排除内容

本机Key与Token；私有.env；课程原件及课程文档全文；教育题集与原始问答；模型权重；Python环境；数据库导出；VM快照；用户路径与私有地址；未经筛选的原始运行日志；根目录不完整历史包。
