# 工程决策记录

|决定|原因与代价|
|---|---|
|复用已有工程、环境和缓存|保护用户已有资源；应用使用独立叠加环境，跨机器仍需重新配置|
|保留API/Service/Processor/Utils与BaseNode合同|便于逐章对照；旧不完整外层包留在本机但不作为发行入口|
|统一模型认证元组|防Key/URL/模型来自不同配置层；改配置需重启单例客户端|
|qwen-plus替代不可用qwen3-plus|真实接口返回404；名称纠正有独立失败证据，不伪造指定模型成功|
|独立数据namespace与不可变版本|重复导入安全；跨库最终提交仍存在孤立资源，需要审计|
|DOCX原生适配、PDF使用MinerU|Word结构可直接提取；复杂版式范围明确限制|
|BGE learned sparse + dense|与实际模型一致，不能宣传BM25|
|RRF仅本地与HyDE，web在重排阶段合并|保持详细课件关系；本次web未启用|
|512token重排pair上限|来自实际模型结构和故障复测，不盲目提高上下文|
|先校验引用后推送完整答案|避免把伪造引文先显示给用户，牺牲逐token体验|
|持久SQLite事件与Mongo整轮历史|SSE重连可重放、历史不半写；部署约束为单worker|
|原始失败保留、只发布脱敏汇总|可审计而不泄露课程内容、Key和用户环境|
|先私有交付，再确认公开|课程衍生许可未知；不擅自给全仓库添加MIT|
