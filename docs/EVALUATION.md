## 运行方式

先真实导入 `examples/public/manual/掌柜智库 图文表格手册.docx`。导入同名文件内容不变会复用版本。

```powershell
.venv_app/Scripts/python.exe scripts/evaluate.py --dataset examples/public/evaluation20.json --validate-only --output artifacts/verification/baseline/public-validation
.venv_app/Scripts/python.exe scripts/evaluate.py --dataset examples/public/evaluation20.json --output artifacts/verification/baseline/public-run-NEW
```

输出目录必须是新的，脚本拒绝向已有问题日志追加并混淆两次运行。每题写入JSONL，最后写summary。若有任务失败进程非0退出，同时保留全部结果。全60题的私有数据与日志仅供本机审查。
